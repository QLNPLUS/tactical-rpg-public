## Fonts

The journal interface selects the vanilla Minecraft font: every UI page sets
`<meta name="aui-font-mode" content="mc">`, and no page, stylesheet or class references a bundled
font file. An isolated client loaded the no-`.ttf` candidate JAR and displayed the nearby-battle
list and battle menu. This check used a development launcher, not a formal launcher profile, and
was not a glyph-by-glyph rendering audit. Packaging gate: `tools/check_release.py` rejects any
`.ttf` in the JAR.

No third-party font file is part of this public source snapshot, and none is packaged in the build.
The private development tree that this snapshot was exported from still keeps one unused leftover
file, `ui/lxgw3500.ttf` — LXGW Marker Gothic Regular, version 1.003, SIL Open Font License 1.1 — for
history only; that file is **not** included here, is **not** packaged, and no page, stylesheet or
class references it. Its OFL text is retained in this snapshot byte-identically from the pinned
upstream commit, as the license record of that file:

- Upstream: <https://github.com/lxgw/LxgwMarkerGothic>
- Pinned commit: `259e6a259ff58698b10a37c8d55a9bfbc393da88`
- License file: `licenses/LXGW-MarkerGothic-OFL.txt` (git blob `b1be6f2f9fcde281ee45561be2c24c2667302d63`)
- Copyright line: "Copyright 2021-2026 The LXGW Marker Gothic Project Authors"

The font is not relicensed by Tactical. Because no font is distributed in the JAR, its OFL text is not
