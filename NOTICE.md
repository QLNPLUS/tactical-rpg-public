How replacement works: retaining the nested JAR's path `META-INF/jarjar/YiRanExpressionLib-1.0.1.jar`, its Maven/mod identity and the `META-INF/jarjar/metadata.json` entry (JarJar range `[1.0.1]`) is the documented mechanism by which a loader selects one shared library, and by which users may swap in an interface-compatible modified version. ## Fonts

The interface renders its text with Minecraft's own font renderer; no page, stylesheet, class or
resource of this project references a bundled font file, and `tools/check_release.py` rejects any
`.ttf` in the JAR. The native screens were accepted on a development launcher, which is not a
glyph-by-glyph rendering audit of a formal launcher profile.

The retired page sources kept one third-party font file in the repository for history only, and it
was never packaged after 0.23.0: `ui/lxgw3500.ttf` — LXGW Marker Gothic Regular, version 1.003,
licensed under the SIL Open Font License 1.1. The font and its licence text were removed from the
source tree together with the retired page sources in the `ui_remake` stage D, because nothing
referenced them any more. Their provenance is recorded here rather than dropped:
