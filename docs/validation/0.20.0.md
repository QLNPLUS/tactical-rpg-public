# 0.20.0 验证记录

## 范围与环境

- 分支：`main`，仅 Minecraft 1.21.1 / NeoForge 21.1.216；ApricityUI 1.2.8；实际客户端加载 Dungeons Perspective 3.6.3。其他加载器/版本未移植、未验证。
- 执行时间：2026-10-23 至 2026-10-24（本机 Asia/Shanghai）。服务端使用 JDK 21，各个独立测试世界串行运行。
- 由 agent 独立启动 `runClient`；输入经 Minecraft 原生键盘/鼠标回调，测试命令只负责布置场景与调整属性，不以直接发送战斗意图代替点击。

## 构建与纯测试

`:common:test :neoforge-1.21.1:build` 通过：common **45**、NeoForge **75**，合计 **120** 项，失败/错误/跳过均为 0。

新增纯规则测试覆盖方向锥边界、旋转、未知/非有限来向、极端坐标、独立乘区、高差取整/上下限、费用向上取整、回合积攒和溢出边界。网络测试核对实际费用、恢复量与成功操作计数完整往返。

最终 JAR 检查通过：资源包格式 34，Mixin 配置及类、UI 资源、36 槽资源、方向伤害/箭矢快照/扩展事件/平滑血条类均存在；无开发辅助模组代码。网络注册版本为 **5**，客户端与服务端都必须更新到 0.20.0。

另外执行旧 `serverSelfTest` 启动/移动/回合 smoke：正常启动并保存退出；它只输出过程日志，没有独立 PASSED 标记，因此不将其算成新的专项证明。其回合结算实际由 AP 4 恢复到 54，未补满。

首次 AP 场景的射线被邻近测试实体挡住，正确保留 AP 65/操作数 3；修正测试弹道后专项通过。另有旧默认费用断言仍期待 1 AP，更新为实际新默认 15 AP 后重新构建，最终 120 项全通过。首次客户端脚本还修正了重生按钮坐标和箭矢目标搜索区域，这些是输入夹具问题，不作为功能通过证据。

## 真实客户端验收

### 站位与高差

同一把木剑对同一无甲苦力怕，分别重新布置方向后真实点选：

- 正面：HP 200 → **196**，4 伤害。
- 侧面：HP 200 → **195.2**，4.8 伤害。
- 背面：HP 200 → **194**，6 伤害。
- 高三格箭矢：原生弓发射并命中，最终这一轮 HP 200 → **193.1**，纪事明确记录高差 **×1.15**。原版弓暴击会影响基础伤害，不用不同发射之间的绝对伤害比较来推断高差；固定基础伤害已由原生服务器专项校验。

### AP 共用涨费、积攒与属性

通过实际菜单、快捷栏和目标点击完成：

1. 开局 **100 / 150**，无额外首回合恢复。
2. 近战付 **10** → 90，菜单下一次攻击显示 **13**。
3. 切换水瓶并使用，付 **10** → 80。
4. 切换石头放置，付 **15** → 65。
5. 再近战付 **18** → 47。
6. 点结束回合并确认朝向，下一自身回合为 **97**，攻击报价恢复 10。
7. 原生命令把 `tactical:ap_recovery` 改为 20，当前 AP 不增加，菜单恢复说明即时变 20；后续自身回合 **117 → 137 → 150**。
8. 真实点击移动，支付原移动费用，攻击仍报价 10，未增加付费操作计数。

### 头顶血条

- 初版在真实镜头下只有约 2 px 高，评审后扩大为 1.08 × 0.18 世界单位，移除亚像素装饰；最终截图可辨认暖红敌方、青绿玩家与金色当前行动者边框。
- 位置插值与 Minecraft 1.21.1 实体模型使用相同的 `xOld/yOld/zOld` 和实体专用帧间比例，并包含渲染偏移；不另加滞后的平滑滤波。填充与边框使用独立深度，避免共面闪烁。
- 真实鼠标选择移动，临时将测试 tick rate 设为 10，捕获 **18 张连续游戏帧**，结束后恢复 20。检查移动开始、中段与终点：血条保持在模型头顶，没有原来逐 tick 独立跳位或明显拖尾。该慢速场景用于暴露插值问题，不表示所有硬件都可保证固定帧率。
